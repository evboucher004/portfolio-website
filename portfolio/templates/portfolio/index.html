About Me

I graduated from Southern New Hampshire University with a Bachelors Degree in Computer Science. I love to play video games, TCG games, build PCs, and read books. I currently work retail, and code small programs on the side.

What I Could Improve On

There are many aspects of these project that could be improved upon, as they are all projects from my past. But they also show how I have improved since that point in time. Looking back at these projects I notice elements that could have been done better then, but are also elements that I still need to improve on now.

There are three main aspects that need improvement; Comments, Readability, and Optimization.

I have only worked solo on projects so far and am not used to working on a team. This means that good commenting is not a strong suit of mine, as it is not needed in the same way when working solo versus working on a team.

The Projects

There are three projects that I have selected to be displayed on this portfolio, and this section will give a brief introduction into what they are. All three projects created solely by me. Each project has the GitHub repository linked on the page, and the repositories have images depicting the main functions of the applications/websites.

Portfolio Website:

A website is designed to showcase a few of the projects that I have created. It was also created with the intent of learning how to host a website, and to do it on a raspberry pi.

MTG Deck Downloader:

A program to download a Magic The Gathering commander deck from Moxfield. It downloads all the cards as images, intended to be used with Tabletop Simulator.

SNHU Website Redesign:

A redesign of the Southern New Hampshire University student portal. This was done as a major project during my time attending SNHU and was used as a reference for the current updated portal.
